# php-basics-practice

## 概要

COACHTECH 教材 Tutorial 7-1「PHPの基礎 ハンズオン演習」で作成した成果物です。
PHPを使用して、商品の小計・消費税・合計金額を計算し、
HTMLで表示するプログラムを作成しました。

## 使用技術

- PHP 8.2
- HTML
- Docker
- Nginx

## 学んだこと

- PHPの変数と計算方法
- PHPとHTMLの組み合わせ方
- number_format() を使った金額の表示方法

## 動作確認

Docker環境を起動します。

Webブラウザから price_calculator.php にアクセスします。

商品名、単価、数量、小計、消費税、合計金額が正しく表示されることを確認します。

計算結果の例

商品名：ノートパソコン

単価：80,000円

数量：2個

小計：160,000円

消費税（10%）：16,000円

合計金額：176,000円
